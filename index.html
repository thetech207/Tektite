Tektite

Version 1.4 — September 24, 2026
Developed by Curtis Brown & Devin (Cognition)

A minimal Obsidian-style daily journal.
One HTML file, no dependencies, your notes stay on your disk.

Ctrl/⌘+P quick-open any note · Ctrl/⌘+Shift+F searches inside notes · [[name]] links between notes

Pick a folder — notes save there as plain .md files in YYYY/MM - Month/YYYY-MM-DD.md.

Ctrl/⌘+E edit ↔ preview   Ctrl/⌘+S save   Tab/Shift+Tab indent

Enter on a list line → next item · Enter on empty item → end list

Right-click a file or folder in the tree for the context menu:
open in new tab · new note/folder · rename · move · trash · delete

Drag items in the tree to move · drop or paste files to attach · search box filters filenames
